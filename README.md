Descripción del proyecto

Este proyecto consiste en desarrollar una página web para un emprendimiento de metalmecánica, con el propósito de presentar sus servicios y productos, dar a conocer el negocio y facilitar el contacto con posibles clientes. La página se está construyendo desde cero utilizando HTML semántico y CSS para organizar el contenido y mejorar su presentación visual.

Avances realizados

Se creó la estructura inicial del sitio web con HTML.

Se agregó un encabezado con el nombre del emprendimiento y un menú de navegación.

Se organizaron las secciones Inicio, Nosotros, Servicios, Productos, Galería y Contacto.

Se incorporaron descripciones de los servicios y productos metalmecánicos.

Se agregaron enlaces internos para navegar entre las secciones.

Se creó el archivo styles.css y se aplicaron colores, fondos, espacios y bordes.

Se mejoró la presentación de las tarjetas de servicios y productos.

Se agregó un formulario visual de contacto con campos para nombre, correo electrónico, asunto y mensaje.

Se incorporó un pie de página con el símbolo de copyright, el año y el nombre del responsable.

Estado actual

La página cuenta con su estructura principal, navegación, estilos visuales, formulario de contacto y pie de página. El formulario es únicamente visual y todavía no envía información. Queda revisar el resultado final
