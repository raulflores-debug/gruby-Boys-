6. Ayuda para revisar el código

¿Dónde se cuentan las vecinas? En la función contarVecinas(). Esta revisa las ocho posiciones alrededor de una celda y suma las que están vivas.

¿Por qué se usa una copia? En siguienteGeneracion() se conserva el tablero anterior y se calcula un tablero nuevo. Así, todas las células se actualizan usando la misma generación anterior, sin que una actualización afecte el cálculo de otra.

Prueba de actualización incorrecta: para experimentar con el error, en el código busca const anterior = copiarTablero(tablero);. Si se reemplaza por una referencia al mismo tablero y se modifican sus celdas mientras todavía se cuentan vecinas, los cálculos posteriores pueden usar valores ya modificados. Por eso el resultado deja de corresponder a una generación simultánea.
